# RFQ Management System Website

This is a React/Vite website prototype for RFQ management.

## Deploy to Vercel

1. Create a GitHub account if you do not have one.
2. Create a new GitHub repository, for example: rfq-management-system
3. Upload all files from this folder to the repository.
4. Go to Vercel.
5. Click Add New Project.
6. Import your GitHub repository.
7. Framework Preset: Vite
8. Build Command: npm run build
9. Output Directory: dist
10. Click Deploy.

## Notes

This version stores data in browser memory only. For real permanent online storage, connect Supabase/PostgreSQL next.
